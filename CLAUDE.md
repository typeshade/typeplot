# TypePlot maintenance

Answer the owner in Korean. Keep code, comments and repository documentation in English.
Use named TypeShade callbacks and real shader imports. Browser exports must not import the
compiler or TypeScript. Build output and declarations are committed so Git installs work
without compiling the dependency. Keep the shader sources and Apache notices in the package.

Use a branch and a draft pull request for every task. Push each commit. Do not push main
directly or force push. Merge only with the owner's instruction and green checks on the
current head. Keep at most three sub-agents active; stop their processes before reporting.

Run npm run build to regenerate dist and declarations. Run npm run examples to regenerate
the two example manifests. Do not add or run tests unless the owner requests verification.
The browser and compile-time entry points must remain separate. CI checks their build output.

All plot graphics, including grids, axes, ticks, text and series, must be generated by named
TypeShade shaders. Host code supplies data, layout, resources and interaction only. Do not add
Canvas 2D, SVG, DOM overlays or handwritten WGSL/GLSL as an alternate chart renderer. PNG
exports must read the TypeShade-rendered output; encoding pixel bytes on the host is allowed.
Use orthographic projection in 2D. Spatial plots default to perspective and also allow
orthographic projection. Pointer dragging must track input directly rather than restarting
an eased camera transition on every move.
Website work follows website/PRODUCT.md and website/DESIGN.md (the TypeNN site conventions).

Prefer direct procedural SDF/field evaluation over host-created path meshes. Dashes repeat
in curve parameter coordinates; do not add screen arc-length accumulation passes. Keep
input data resident across camera changes. Let TypeShade Runtime own rendering and Device
own compute resources; use fuse for real compatible kernel chains and inspect its report,
not as a wrapper for draws or a claim that every pass is fused. Axes default to 1 CSS px.
